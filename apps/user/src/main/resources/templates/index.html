Module Structure

mono-repo-thymeleaf/
├── apps/
│   └── user/              # Spring Boot App
└── libs/backend/
    ├── common/            # Entity, Payload, Utils
    ├── global-core/       # Config, Exception, Event
    ├── domain-core/       # Domain Logic (CQRS)
    ├── security-web/      # Auth / Guard Filters

common ← global-core ← domain-core ← security-web ← web-support ← apps
